Automatic import on iPhone

iPhone apps can't read your texts directly, but a Shortcuts automation can pass each new bank SMS to Ledger the moment it arrives.

  1. Open Shortcuts → Automation → + → Message.
  2. Leave Sender empty (banks like Arab Bank text from a name, not a contact). Set Message Contains to a word every bank alert has, such as JOD (or دينار for Arabic alerts; add a second automation for each). Choose Run Immediately and turn off Notify When Run.
  3. Add the action URL Encode with input Shortcut Input → Content.
  4. Add Text and type this link, then insert the URL Encoded Text variable at the end:
  5. Add Open URLs with the Text from step 4. Done.

Other texts that happen to contain your word are ignored: Ledger only keeps messages it can read as a transaction.

Tip: the automation opens Ledger in Safari, so use Ledger in Safari (bookmark it) for your data to stay in one place. Home-screen apps on iPhone keep separate storage.

⚠️ You opened Ledger from a Home Screen icon. This copy has its own data: messages from the automation go to Safari, not here. Export a backup here, import it in Safari, and re-add the icon with Open as Web App turned off.
